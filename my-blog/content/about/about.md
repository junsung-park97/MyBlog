# MyBlog에 오신 것을 환영합니다!

이 블로그는 개발과 기술에 대한 이야기를 나누는 공간입니다.
Next.js, TypeScript, Supabase 등 현대적인 웹 기술을 활용하여 구축되었습니다.

## 기술 스택

### Frontend
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Markdown**: remark, rehype

### Backend
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Storage**: Supabase Storage

### DevOps
- **Deployment**: Vercel
- **Version Control**: Git & GitHub

## 주요 기능

### 렌더링 전략
- 🚀 **Server-Side Rendering (SSR)** - 동적 콘텐츠를 서버에서 렌더링
- 📊 **Static Site Generation (SSG)** - 빌드 타임에 정적 페이지 생성
- 🔄 **Incremental Static Regeneration (ISR)** - 주기적으로 페이지 재생성

### 디자인 & UX
- 🎨 **반응형 디자인** - 모바일, 태블릿, 데스크톱 지원
- 🌙 **다크 모드** - 자동 다크 모드 지원
- ⚡ **빠른 로딩** - 코드 스플리팅 및 최적화

### 콘텐츠 관리
- 📝 **마크다운 기반 포스팅** - 간편한 콘텐츠 작성
- 🏷️ **태그 시스템** - 포스트 분류 및 필터링
- 🔍 **SEO 최적화** - Open Graph, 메타데이터 자동 생성

## 아키텍처 패턴

이 블로그는 **Atomic Design** 패턴을 따릅니다:

- **Atoms**: Button, Tag 등 기본 요소
- **Molecules**: PostCard, PostHeader 등 조합 요소
- **Organisms**: Header, Footer, PostList 등 복합 요소
- **Templates**: 페이지 레이아웃
- **Pages**: 실제 페이지

## 성능 최적화

- ✅ Next.js Image 컴포넌트 사용
- ✅ 코드 스플리팅 및 lazy loading
- ✅ 폰트 최적화 (Geist Sans, Geist Mono)
- ✅ Tailwind CSS purge로 CSS 최적화
